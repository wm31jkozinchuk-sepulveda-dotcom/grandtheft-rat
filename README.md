# Grand Theft Rat

A small playable 3D browser game prototype inspired by GTA-style open-world crime chaos, but starring a rat.

## Play locally

1. Open a terminal in this folder.
2. Run:
   ```bash
   python3 -m http.server 8000
   ```
3. Open:
   ```text
   http://localhost:8000
   ```

## Controls
- W/A/S/D: move
- Shift: sprint
- E: steal a nearby parked car or exit the car
- R: restart after being caught

## Goal
- Steal loot and cash
- Escape the cops
- Survive the city as the most wanted rat in town

## Notes
This is a lightweight browser game prototype built with Three.js and designed for easy deployment to Netlify.
